# Seed Examples

These are **seeds**, not exemplars. A seed becomes an exemplar only after you adapt it to a real page or endpoint in
your project, make it run, show it can fail, and list it in `.claude/exemplars.yaml` (phase 6).
The seeds use TypeScript with Vitest and Playwright. Translate them to your language. Keep the shape.

Each seed shows the pattern. Replace every placeholder name (`example.test`, `/orders`) before use.
